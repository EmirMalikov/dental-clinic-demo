# Сайт стоматологии с онлайн-записью (демо)

Демо-сайт для стоматологических клиник: пациент сам выбирает услугу, врача, день и свободное время, а клиника сразу получает уведомление в WhatsApp или Telegram.

«Ак Жылмаюу» — вымышленная клиника, имена врачей и цены условные.

## Что показывает демо
- Карточка «Ближайшее свободное время» на первом экране
- Услуги и цены в сомах
- Онлайн-запись: услуга → врач → день → время → имя и телефон (+996)
- Пример сообщения, которое получает клиника
- Журнал записей для администратора
- Мобильная версия с кнопками «Записаться» и «Позвонить»

Одна страница: HTML, CSS и JavaScript без зависимостей.
